# UT ML Academy

This is a collection of the work that I did while attending the UT Academy for All: Machine Learning Edition.

## Contents

- **Classification/** — Perceptron and KNN classification exercises (binary, multiclass, Pacman agent), plus supporting helper modules.
- **KNN/** — K-nearest neighbors implementation and exercises using the Iris dataset.
- **ReinforcementLearning/** — Reinforcement learning exercises built on the Pacman/Gridworld/Crawler environments.
- **LDOS Notebooks/** — Exploratory data analysis, model building, and KNN notebooks, with accompanying datasets.
- **Final Challenge Notebooks/** — Final challenge submission notebooks.
- **PythonPractice/** — Introductory Python practice scripts.
- **rainsong_data/** — Labeled dataset used across exercises.
